## نقطة الاستئناف

- فرع العمل `feature/landing-pwa`. تحقق GitHub من الإصدار السابق `6deeff2de96d908ae57ff9a7e53e0afc0ae10c3c`.
- بدأ التنفيذ السابق ترجمة الواجهة وأجرى اختبار متصفح للإصدار السابق. خلّفت المحاولة الأولى خطأ اتصال بالمتصفح، وخلّفت المحاولة التالية لقطات محلية وخطأ أثناء حذف ملف تعريف المتصفح. يلزم تسجيل نتيجة قابلة للتحقق قبل اعتماد الاختبار.
- تحديث الواجهة يستعمل «كل طلباتك في مكان واحد» وبطاقة «شحن و توصيل» ووصف «طيار / سيارة / نقل»، مع تحكم ذهبي AR/EN يحفظ التفضيل ويضبط اتجاه النص. تبقى شاشة البدء بشعار «سوقك الذكي لكل طلباتك» ومدة 4000 مللي ثانية شاملة التلاشي.
- أصول الإصدار والنسخ الاحتياطية محفوظة. تُضم إلى الإصدار الملفات التي تؤثر على الواجهة فقط.
- التسجيل واجهة معاينة. تكامل تحقق واتساب الفعلي مؤجل. تبقى عمليات جمع المنتجات السبع متوقفة.
- بعد التحقق من الواجهة محليًا، يُرفع إصدارها إلى الفرع ثم يُنشر في مشروع Cloudflare Pages الحالي ويُتحقق من عنوان الإنتاج. بعدها تبدأ مرحلة جرد الخدمات والأصول السحابية وتوثيق تبعياتها قبل أي تنظيف.

## قيود التشغيل والاستضافة

تعمل اختبارات المتصفح والبناء بالتتابع. تُراقب الذاكرة والتبديل والضغط والمعالج والقرص بين المراحل. تخزين الإنتاج وخدماته في السحابة المعتمدة، واللابتوب للتنفيذ والاختبار المؤقت. تُحمى أصول التصميم والبيانات والنسخ الاحتياطية وموارد الاسترداد.

## بناء إصدار الواجهة

من مجلد `app` بعد تثبيت الاعتماديات المقفلة، تُشغّل الأوامر بالتتابع.

```bash
./node_modules/.bin/eslint src next.config.ts
./node_modules/.bin/tsc --noEmit
SAFAQAT_PAGES_EXPORT=1 RAYON_NUM_THREADS=1 UV_THREADPOOL_SIZE=2 NEXT_TELEMETRY_DISABLED=1 NODE_OPTIONS=--max-old-space-size=768 npm run build -- --webpack
```

ينتج التصدير الثابت في `app/out`. يعمل إعداد التصدير عند تمرير `SAFAQAT_PAGES_EXPORT=1`. يُرفع التصدير إلى مشروع Pages `safaqat` على فرع النشر `production` مع إسناده إلى الالتزام المرفوع في GitHub. معرّف نشر الإصدار السابق `fd8640e5-bb2e-43e5-95d2-78409ed324e0`، ومرجع الإصدار الذي سبقه `82915eca-03bf-4f43-8d56-253b271c8473`.
